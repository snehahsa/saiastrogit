# 🌑 Astroverse X

### Welcome to the next generation social metaverse experience.

Astroverse X is a browser-based multiplayer universe where players can explore space, survive dangerous environments, socialize with other players in real time, compete in game modes, discover hidden rewards, and participate in a growing on-chain ecosystem powered by $ASTROVERSE.

Built for both casual players and competitive explorers, the Astroverse combines social interaction, space survival, racing, treasure hunting, and digital ownership into one connected universe.

### Core Features

* Real-time multiplayer universe
* Space survival gameplay
* Social multiverse hubs
* Racing mode
* Treasure hunting events
* On-chain advertising system
* Browser-based gameplay
* Mobile + desktop support
* Future VR expansion
* Community-driven ecosystem

The Astroverse is designed to evolve continuously with new sectors, game modes, rewards, events, and social systems.
